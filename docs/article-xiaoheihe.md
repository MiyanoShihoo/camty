# [分享] 开源了我的红队渗透工具：一条命令自动打完整场，带证据链 + AI 引擎 + C2

## 先看效果

一条命令跑完一场完整交战：

```
python -m camty auto target.yaml
```

输出：存活探测 → 漏洞验证 → 注入探测 → 越权测试 → 报告 + docx，全程审计留痕，每步证据自动归档。

带 AI 引擎的模式更猛——LLM 规划者自己决定下一步打哪里：

```
python -m camty engine target.yaml --agent --budget 30
```

> 七页签面板：力导向资产覆盖图、流量回放、攻击链、探索图……跑动中你随时可以插一句"换个方向"。

## 这是什么

Camty——红队交战工作台。

简单说就是把渗透测试的整个流程（侦察→验证→利用→横向→报告）变成了**一条流水线**：

- **41 个工具适配器**：从子域名发现到 Kerberoasting 到 C2 会话管理，全链覆盖
- **AI 多 Agent 引擎**：GLM-5.3 做规划者，N 个 worker 并行执行，根据战况动态调整攻击链
- **浏览器自动化**：过 Turnstile/反 bot 检测，注册登录拿会话全流程自动化
- **Chrome TLS 指纹伪装**：全部流量伪装成真实 Chrome，WAF 看不出是脚本
- **自研 C2**：纯 C 写的植入体，AES 加密 + 无文件加载 + 流量伪装，全程 E2E 测试通过
- **Web 面板**：跑动中实时看资产覆盖图、流量回放、攻击链

## 为什么造它

写报告的时候发现：工具输出散落在 5 个终端 tab 里，截图存了 30 张但不知道哪张对应哪个测试。

**信息有了，证据链没建立。**

所以 Camty 的核心设计是：每个动作先过授权范围白名单（范围外直接拒绝），然后落审计哈希链（防篡改），产出进带血缘的证据台账。想利用一个漏洞？必须先引用台账里已验证的发现 ID，不然引擎直接拒绝。

**不是提示你"确认一下"，是直接拒绝。**

## 跑了两个真实目标

1. **Go + GORM 后端站**：25+ 条攻击线全排（注入全参数化、越权全有权限门、JWT 13 万字典没中）——最后能输出"测过了、确实没洞"的证据支撑结论，这本身就是交付物
2. **个人站**：三阶段打完（人工 15 线 + AI 引擎 25 步 + 旁路端口扫描）——AI 引擎发现了我漏掉的旁路测绘方向

## 技术亮点（简短版）
